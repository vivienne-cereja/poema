# poema

A markdown editor made by Vivienne and Leo, from scratch, our own way. Nothing here copies another project out of habit: what we did somewhere else can answer a question, but it is never the template.

## Commits

Every commit is a verse. In English, lowercase, short, saying what changed in the life of the poem, not which file was touched. No prefix: the whole repository is already the poem. Read from the bottom up, `git log` tells how it was born.

Technical detail goes in the body, for whoever wants to know.
